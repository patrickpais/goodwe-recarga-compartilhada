Faixa de aviso que explica um estado ou uma regra no lugar onde ela age.

Quatro tons, cada um com um significado fixo: `info` para esclarecimento e pré-autorização, `reduced` para o controle dinâmico de carga atuando, `danger` para falha e pendência financeira, `success` para conclusão e economia.

Todo aviso tem três partes: o que aconteceu em linguagem comum, o efeito financeiro quando houver, e uma ação. "Falha na comunicação com o carregador. Nada foi cobrado. Tentar de novo ou falar com o suporte." Um aviso sem a linha do dinheiro faz a pessoa presumir o pior.

O tom `reduced` é o mais importante do conjunto: ele é quem impede que o motorista leia a atuação do DLM como defeito do equipamento. Nunca use `danger` para redução de potência.

O consumidor fornece o texto. Não use este componente para conteúdo permanente da tela — ele é para o que mudou agora; regra fixa vai no corpo da tela.
